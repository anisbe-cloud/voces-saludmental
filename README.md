# Foro Voces por la Salud Mental · UAEH

Página institucional estática preparada para GitHub Pages.

## Publicación en GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `foro-voces-salud-mental`.
2. Sube `index.html`, `programa.jpg`, `qr-registro.png` y `logos-institucionales.jpg` a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)` y guarda.
6. GitHub generará la URL pública del sitio.

## Streaming
En `index.html`, busca:
`const STREAM_URL=''`
y coloca el enlace de YouTube cuando esté disponible.

## Ponentes
Las tarjetas muestran iniciales como espacio temporal. Pueden sustituirse por fotografías oficiales y las reseñas curriculares.
